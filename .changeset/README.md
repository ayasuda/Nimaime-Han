# Changesets

This folder is managed by [Changesets](https://changesets.dev). Every pull request that changes
what users of `nimaime-han` get (the published `dist/`, the CLI, the Sanmaime language, or the
documented behaviour) adds a changeset here with `npm run changeset`.

See [CONTRIBUTING.md](../CONTRIBUTING.md#changesets) for how to write one and
[docs/releasing.md](../docs/releasing.md) for how releases are made.
