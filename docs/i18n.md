# Sanmaime keyword languages (i18n)

Sanmaime keywords can be written in several languages, like Gherkin's
`# language:`. The normative rules are in [sanmaime.md §3.4–§3.5](./sanmaime.md);
this page describes the keyword dictionaries, the parser API and how to add
a language.

## Choosing a language

```text
# language: ja
画面: ログイン

  要素: ログインフォーム
    表示: メールアドレス
    かつ: パスワード

  要素: ログインボタン
    条件: 入力が正しい
    有効
```

1. A valid `# language: <code>` directive in the file header wins.
2. Otherwise the configured default applies: `defineSanmaimeConfig({ language: 'ja' })`
   ([config.md](./config.md)), passed to the parser as `parse(source, { language })`.
3. Otherwise `en`.

| Keyword (canonical)   | `en`          | `ja`      |
| --------------------- | ------------- | --------- |
| Screen                | `Screen:`     | `画面:`   |
| Element               | `Element:`    | `要素:`   |
| When                  | `When:`       | `条件:`   |
| Show                  | `Show:`       | `表示:`   |
| Hide                  | `Hide:`       | `非表示:` |
| And                   | `And:`        | `かつ:`   |
| Enable                | `Enable`      | `有効`    |
| Disable               | `Disable`     | `無効`    |
| Background (reserved) | `Background:` | `背景:`   |

Japanese name keywords also accept the full-width colon: `画面：ログイン`.

## Dictionary format

Dictionaries live in `src/parser/languages.ts` (the equivalent of Gherkin's
`gherkin-languages.json`) and are exported from `nimaime-han/parser`:

```ts
import { LANGUAGES, getLanguage, type LanguageDefinition } from 'nimaime-han/parser';

interface LanguageDefinition {
  code: string; // "ja"
  name: string; // "Japanese"
  nativeName: string; // "日本語"
  colons: readonly string[]; // [":", "："]
  keywords: {
    screen: readonly string[]; // ["画面"]
    element: readonly string[];
    when: readonly string[];
    show: readonly string[];
    hide: readonly string[];
    and: readonly string[];
    enable: readonly string[];
    disable: readonly string[];
    background: readonly string[]; // reserved (SANMAIME_E019)
  };
}
```

- Spellings are stored **without** the colon. The lexer appends one of
  `colons` to name keywords (`screen` … `and`, `background`) and matches bare
  keywords (`enable`, `disable`) against the whole line.
- Each slot is an array so a language can define synonyms. The **first**
  spelling is the primary one: diagnostics quote it and tools that write
  Sanmaime should use it. When synonyms overlap, the longest match wins.
- `LANGUAGES` and its definitions are frozen. `getLanguage(code)` returns
  `undefined` for unsupported codes. `SUPPORTED_LANGUAGES` lists the codes.

## Parser API

```ts
parse(source, { uri, language: 'ja' });
```

- `language` is the default for a file without a valid directive. The
  directive always wins; `document.language` is the effective language and
  `document.languageDirective` records the directive as written.
- An unsupported `language` option throws a `TypeError` (a configuration
  error). An unsupported directive is the diagnostic `SANMAIME_E017`, after
  which the default language is used.
- The AST is language-independent: `Expectation.keyword` is always the
  canonical English keyword (`'Show' | 'Hide' | 'And' | 'Enable' | 'Disable'`).
- Messages stay in English, but keywords quoted in them follow the file's
  language (`'要素:' must appear inside a '画面:'.`). A keyword of another
  language gets a hint:
  `'Show:' is a keyword of English (en), but this file uses Japanese (ja) keywords. Did you mean '表示:'?`

## Adding a language

1. Add a `LanguageDefinition` to `LANGUAGES` in `src/parser/languages.ts`.
   Every slot needs at least one spelling; spellings must be trimmed, must
   not contain a colon or start with `#` or `@`, and must be unique within
   the language (`test/parser/languages.test.ts` checks this for every
   language).
2. Add valid fixtures `examples/sanmaime/valid/<code>-*.sanmaime` (and adapt
   the language check in `test/parser/fixtures.test.ts`) plus invalid
   fixtures for its keywords.
3. Add a column to the keyword table in [sanmaime.md §3.5](./sanmaime.md)
   and to the table above, and update `language-code` in §4.1.
4. Extend the `.sanmaime` editor grammar, if any, with the new spellings.
